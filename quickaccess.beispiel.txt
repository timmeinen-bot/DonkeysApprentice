# Donkey's Apprentice -- Beispielliste

# Diese Datei geht mit dem Paket. Beim ERSTEN Start wird daraus
# quickaccess.txt gemacht; ab dann wird nur noch quickaccess.txt gelesen
# und diese Beispieldatei nie wieder angefasst.
#
# Format:
#   [Gruppe]                 wird zur Überschrift
#   Name = Ziel              Datei, Ordner oder Adresse
#   Name = Ziel | Quelle,Nr  eigenes Symbol, z.B. shell32.dll,44
#   Ziel                     ohne "=": der Dateiname wird zum Namen
#
# Umgebungsvariablen in Prozentzeichen werden aufgeloest, die Liste
# funktioniert also auf jedem Rechner. Ziele, die mit "shell:" beginnen,
# oeffnet der Explorer (Sonderorte wie der Papierkorb).
